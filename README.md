# SkillHub LMS - Full Stack with bKash & Admin

Modern LMS built with MERN Stack.

## Features
- Course Management, Enrollment, Progress Tracking
- Admin Panel (users, courses, payments)
- bKash Payment Integration (manual verification)
- JWT Auth, Roles: student/instructor/admin

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- DB: MongoDB (or JSON for demo)

## Quick Start

### Backend
```
cd backend
npm install
npm run seed
npm start
# http://localhost:5000
```

### Frontend
```
cd frontend
npm install
npm start
# http://localhost:3000
```
